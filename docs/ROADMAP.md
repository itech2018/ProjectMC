# ProjectMC Roadmap

## v0.0.x — Foundations

- [x] Monorepo layout
- [x] C++20/CMake build
- [x] Shared version library
- [x] Game executable bootstrap
- [x] Dedicated server bootstrap
- [x] Launcher/platform placeholders
- [x] Architecture documentation
- [x] Windows/Linux CI

- [ ] Input abstraction
- [ ] Logging/configuration

### v0.0.2 Voxel Foundations
Block/state registry, chunks/coordinates, materials, chunk meshing and block placement/removal.

### v0.0.3 First Playable World
First-person controller, collision/gravity, raycasting, hotbar, terrain prototype, chunk streaming and save/load.

## v0.1–v0.4 — World & Survival
Procedural generation, biomes, caves, structures, inventory, crafting, survival, combat, farming and advanced building.

## v0.5–v0.8 — Core Modded-Style Systems
Mechanical engineering, electricity, fluids, industry, logistics, searchable storage and autocrafting.

## v0.9–v0.12 — Automation & Transport
Logic networks, programmable controllers, railways, freight, vehicles and factory automation.

## v0.13–v0.16 — Exploration & Simulation
Expanded environments, original alternate worlds, creatures, settlements and deeper simulation.

## v0.17–v0.20 — Multiplayer
Authoritative servers, communities, permissions, claims, trading and administration.

## v0.21–v0.24 — Extensibility
Official mod API, data/resource packs and advanced creative/world-editing tools.

## Launcher track
1. install/launch versions

## 1.0 target
A polished voxel sandbox where survival, building, exploration and deep engineering/automation are all first-class ways to play.
